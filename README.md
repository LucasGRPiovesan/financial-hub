# Financial Hub

Financial Hub is the financial system of record for N integrated products: products send business facts
(usage, purchases, consultations) and the Hub turns them, deterministically and auditably, into ledger-backed
money movements, invoices, payments (Asaas Sandbox) and reconciliation.

See [docs/PLAN.md](docs/PLAN.md) for the master plan and [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for local
development. A full README arrives with task 10.4.
